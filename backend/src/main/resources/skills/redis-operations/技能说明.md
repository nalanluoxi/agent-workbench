# Redis 数据库操作

使用用户指定且有权访问的 Redis 连接，先确定数据库、Key、数据类型和具体操作。String、Hash、List、Set、Sorted Set 和 Stream 使用工具支持的结构化命令。

## 只读探索流程

1. 用户要求“展示全部 Key”、“当前库有哪些 Key”或“按前缀找 Key”时，调用 `SCAN`；按前缀查询时使用 `pattern=前缀*`。不得使用或建议 `KEYS *`。
2. 需要读取未知 Key 时，先调用 `TYPE`，然后按类型使用 `GET/HGETALL/LRANGE/SMEMBERS/ZRANGE/XRANGE`。
3. 查看数量时，库级使用 `DBSIZE`，结构级按类型使用 `STRLEN/HLEN/LLEN/SCARD/ZCARD/XLEN`。
4. 检查存在性使用 `EXISTS`；需要毫秒精度和绝对过期时间时使用 `PTTL`，普通秒级剩余时间使用 `TTL`。

读取可直接调用；写入返回待确认时等待用户批准，不得自行批准。Stream 已有消息不能原地修改，解释原因并让用户另行决定是否追加更正消息。
结果未知时提醒用户核查，不自动重复写入。
